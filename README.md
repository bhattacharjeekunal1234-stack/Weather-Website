# Weather Website

A simple Weather Website project built using **HTML**, **CSS**, and **JavaScript**.

## Project Status

🚧 JavaScript part is still in progress (not complete yet)

## Features

* Clean and responsive UI
* Weather dashboard layout
* Navigation buttons:

  * Today
  * Forecast
  * Map
  * Alerts
* Live weather data section
* Styled using modern CSS design

## Technologies Used

* HTML
* CSS
* JavaScript (Work in Progress)

## Future Improvements

* Real-time weather API integration
* City search functionality
* Temperature, humidity, wind speed display
* 7-day weather forecast
* Interactive weather map
* Weather alerts system
